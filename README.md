# WiFi Security Auditor

A browser-based defensive Wi-Fi security posture checker for authorized testing.

## Included
- WPA3/WPA2 configuration review
- Local password-strength evaluation
- WPS / guest-network / firmware checklist
- Security score
- Copyable audit report

## Safety
This application intentionally does not perform password cracking, handshake capture, deauthentication, WPS attacks, credential theft, or access-control bypass. Use it only for networks you own or are explicitly authorized to assess.

## Deploy
Deploy as a Next.js application. No backend or database is required for the current browser-only audit mode.

Cloudflare deployment uses the current Next.js 16 configuration.
